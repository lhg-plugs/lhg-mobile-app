# lhg-ma-privacy：隐私合规基础

## 1. 何时使用

- 写隐私政策、准备上架资料时
- 集成了第三方 SDK（推送/统计/崩溃上报），需要声明时
- 申请敏感权限（定位/通讯录/相册/麦克风），需要写使用说明时

**不适用**：已由法务出具正式隐私政策的项目（以法务版本为准）。

**重要声明**：本 skill 给的是通用条款框架与 checklist，**不是法律意见**。正式发布前请找法务/合规确认，各地区法规要求不同。

## 2. 输入与输出

**输入**：App 收集的数据清单、集成的第三方 SDK 清单、公司/开发者联系信息。
**输出**：隐私政策初稿（含""占位项）+ 合规自查清单。

## 3. 隐私政策必要条款（四项缺一不可）

### 3.1 数据收集说明

写清四件事：收集什么、为什么收集、怎么用、保留多久。

- 示例："我们收集您的记账数据与设备信息，用于多端同步与崩溃分析；数据保留 12 个月，到期删除。"
- 反例："我们可能收集必要信息用于改善服务"（什么都没说清，等于没写）

### 3.2 第三方 SDK 声明

列出每个集成的第三方 SDK：名称、用途、它会拿到什么数据。

- 推送 SDK：用于消息推送，会获取设备标识
- 统计 SDK：用于使用情况分析
- 崩溃上报 SDK：用于稳定性监控
- **漏写 SDK 是常见被拒/被下架原因**：代码里集成了，政策里没写

### 3.3 联系方式

给出隐私问题联系人/邮箱（如 privacy@example.com），并承诺响应时限。
用户行使权利（查阅/更正/删除）时找得到人，这是硬性要求。

### 3.4 数据删除与注销

说明用户如何删除账号、注销数据、撤回同意，以及处理时限。
只写"您可以联系我们删除"不够：要写清路径（App 内哪里操作）与时限。

## 5. 权限申请规范

每个敏感权限都要有"使用说明"（申请弹窗里的那句话）：

- 好："需要访问相册，用于上传头像"（干什么说清楚）
- 坏："需要您的权限以提供更好的服务"（等于没说，审核可能被拒）
- 原则：**不用就别申请**。申请的每个权限都要在政策里对应上。

## 6. 常见合规坑

1. **SDK 裸奔**：集成了统计/推送 SDK，隐私政策里只字未提
2. **超范围收集**：记账 App 要通讯录权限，且说不清为什么
3. **注销无门**：政策写了"可注销"，App 里找不到入口
4. **儿童数据**：目标用户含儿童时有额外要求，如实做年龄分级
5. **政策链接 404**：上架时填的隐私政策链接打不开，直接被拒
6. **更新不同步**：App 新增了数据收集项，政策没同步更新

## 7. 反模式（不要这么做）

1. **复制大厂政策改个名字**：条款与你的实际数据收集对不上，被问就穿帮。
2. **"可能收集必要信息"式写法**：模糊表述在审核与监管面前等于没写。
3. **占位链接上架**：隐私政策还是"即将上线"就提交，浪费一轮审核。
4. **把本模板当法律意见**：模板是起点，正式发布前找法务确认。
5. **收集了再补政策**：先上车后补票，监管问询时没有整改时间。

### 3.5 数据安全措施写法

政策里"数据安全"一节不要只写"我们非常重视您的隐私"，要写具体措施：

- 传输加密：HTTPS 传输，证书 pinning（做了就写，没做别写）
- 存储加密：本地数据库加密、云端存储加密
- 访问控制：生产数据访问需审批、日志留存
- 应急：发生数据泄露时的通知机制与时限

写不出的措施 = 没做的措施，先补实现再写政策，顺序别反。

### 6.1 上架前合规自查表

- [ ] 代码里集成的 SDK，政策第 2 节一个不少
- [ ] 申请的每个权限，弹窗文案说清用途，政策里能对上
- [ ] 政策链接在商店后台可打开（手机浏览器亲手点一遍）
- [ ] 注销/删除入口在 App 内真实存在（亲手走一遍）
- [ ] 本次版本新增的数据收集项，政策已同步更新
- [ ] 模板中"【待填写】"全部填完

## 8. 自检与反馈

**质检门**：

- [] 四项必要条款齐全：数据收集 / 第三方 SDK / 联系方式 / 删除注销
- [] 模板中所有""已填，无占位残留
- [] 每个申请的权限都有使用说明，且政策里能对上
- [] 政策链接真实可访问
- [] 已请法务/合规做最终确认（或已排期）

**标准冒烟用例**：`python3 scripts/audit/mobile_audit.py --target <计划目录>`，MA-PRV 类规则清零。

**反馈渠道**：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-mobile-app/issues，正文写清「输入 → 错误输出 → 期望输出」。
